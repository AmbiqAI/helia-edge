Input rank, output shape and configuration differ between families. The individual API pages are the source for each constructor's contract. A family being listed does not establish support for every backend or export format.

## Keep configuration separate from execution

1. Choose the Keras backend before importing model components.
2. Define architecture parameters and input tensors.
3. Construct the model, then initialize or load its weights.
4. Train, evaluate and convert it in the application workflow.

Factories do not select your backend, reset global seeds or export models. Typed parameter objects make architecture choices explicit; they do not include the trained weights or data-processing policy.

## Describe an architecture with a ModelSpec

TCN, TsMixer, ResNet, MobileNetV1, MobileOne, EfficientNetV2, RegNet, ConvMixer, Composer, MetaFormer and Conformer are built from a `ModelSpec`. A spec holds the family's typed parameters and the input shape without the batch axis:

```python
from helia_edge.models import ModelSpec, ResNetParams, build

spec = ModelSpec(params=ResNetParams(input_filters=8, blocks=[{"filters": 8}], num_classes=4), input_shape=(32, 32, 3))
model = build(spec)                 # dynamic batch, for training
deployed = build(spec, batch_size=1)
spec_json = spec.model_dump_json()  # ModelSpec.model_validate_json(spec_json) restores it
```

- **Selecting a family:** each parameter class has a `family` field (`"resnet"` here), so a spec read from JSON builds the right family. The model is named after its family; pass `name=` to `build` to combine two models of one family in a Keras graph.
- **Strict parameters:** parameters are immutable and reject unknown fields. `num_classes` is a parameter: the classes of the output layer, at least 1. With None, most families build without a dense layer; TCN and MobileNetV1 (with `include_top`) and TsMixer refuse to build.
- **Input shapes:** positive sizes, or None for a variable axis.
- **Each family's builder:** `helia_edge.models.<family>.build(params, input_shape, *, batch_size=None, name=None)`.
- **Other families:** UNet, UNext, MiniResNet, FastEnhancer, CorNET, TimePPG, MLPerf Tiny and Silero VAD keep their own constructors; the [typed architecture guide](../typed-architectures/) covers them.
